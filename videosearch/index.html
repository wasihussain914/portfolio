CDL Video Semantic Search · live

Searching video clips + images by what they show, not keywords. Each video is indexed as keyframes embedded with Amazon Nova; a text query is matched to the nearest frames. Green = matched by image content.

Live against the CDL dev-coco stage public API. ~105 MSR-VTT video clips (keyframes) + 300 COCO images. Results collapse multiple frames to one video. Content/vector search via Nova Multimodal Embeddings (3072-d) + pgvector HNSW.
